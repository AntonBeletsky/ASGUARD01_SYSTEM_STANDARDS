# Skylark

Skylark is a **demo landing page** for a fictional drone film studio. It exists to show
what `doc_generator.py` produces for a small vanilla HTML/CSS/JS project.

- two pages (`index.html`, `about.html`)
- one stylesheet with design tokens in `css/vars.css`
- a small ES-module script in `js/`

## Usage

Open `index.html` in a browser. There is no build step.
